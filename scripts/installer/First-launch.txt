FocoNow — installation and first launch

1. Drag FocoNow into Applications.
2. Open FocoNow from Applications.
3. If Apple cannot verify it, go to System Settings > Privacy & Security,
   find FocoNow, click Open Anyway, then confirm Open.

If the verification warning keeps appearing:

Double-click "Copy opening command" in this disk image. Your browser opens
our guide with a Copy command button. Click Copy command, press Command-Space,
type Terminal, press Return, paste with Command-V, then press Return.

Offline? Copy this entire line instead:

xattr -dr com.apple.quarantine "/Applications/FocoNow.app" && open "/Applications/FocoNow.app"

Only use this for a copy you trust from the official website or GitHub.
This removes downloaded-file quarantine from FocoNow only and opens it.
It does not scan for malware or turn off global Mac security.
If the alert says the app contains malware or will damage your Mac, stop.

This preview is not yet notarized by Apple. The web shortcut is a link to
instructions, not an executable installer or automatic approval tool.
